UPSERT POLICY

Stable Business Key = order_id

يوجد Unique Index على order_id. السجل الموجود يُحدّث بدل إضافة سجل مكرر.

business_key = order_id write_mode = upsert unique_index = order_id duplicate_business_records = 0
Raw يمكن أن يحتفظ بتاريخ تشغيل جديد لكل run_id، لكن الحالة التجارية النهائية تبقى فريدة.
